    Interface BBoxIntents

    The editor intents of the bounding box plugin, merged into the editor intents under bbox by the composition root.

    Every intent runs through the layer's existing imperative APIs, which mutate and notify synchronously, so the slice contributor invalidates the snapshot in the same dispatch.
