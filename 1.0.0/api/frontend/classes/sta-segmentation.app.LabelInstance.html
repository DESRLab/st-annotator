    Class LabelInstance

    Represents an object across one or more frames.

    The structure of this agent class is similar to a controller, but since we are wrapping ReadonlySegmentationIndex which is an agent class, we need to perform the coordination at the agent level rather than the controller level. Here, ReadonlySegmentationIndex acts like a model while an internal rendering object acts like a view.
