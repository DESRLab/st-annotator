    mapped

    • mapped<PInner, EInner extends {}>(
          factory: PaneElementFactory<PInner, EInner>,
          paramsMapper: ParamsMapper<P, PInner>,
          eventsMapper: Pick<EventsMapper<E, EInner>, "innerToOuter">,
      ): PaneElementFactory<P, E>

      Wraps a pane element factory so that the wrapper factory constructs a pane element that maps data sent to/from the wrapped pane element.

      The wrapper pane element operates on the params and events of this builder, mapping params to the wrapped pane element, and events from it.

      This allows a pane element that is designed for a particular object to instead operate on an outer object, making it easier to compose PaneElementFactory to work with different types of params and events.

      between the wrapper and wrapped element. Specifies how the events are mapped between the wrapper and wrapped element.
