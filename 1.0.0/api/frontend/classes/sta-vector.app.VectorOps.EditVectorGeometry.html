    • fromParams(
          vector: any,
          mode: string,
          params: VectorGeometry,
          prevVertices?: readonly Readonly<Vector3XYZ>[],
      ): EditVectorGeometry

      Creates a new operation from a set of (unserialized) parameters.

      The vertices are plain Vector3XYZ records; they are serialized to DecimalVector3Data here for the wire and converted back to three.js vectors only when the operation is applied to the index.

      If prevVertices is given, it is used as the undo state instead of reading the current state of the vector.

      Parameters

      • vector: any
      • mode: string
