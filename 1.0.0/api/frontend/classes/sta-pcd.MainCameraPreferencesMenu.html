    Class MainCameraPreferencesMenu<WM>

    Applies and keybinds the main camera settings (view mode / orbit point).

    The committed settings state lives on the main window itself (viewMode plus the orbit-target override); the menu reads it from there instead of keeping a second copy, and the editor state snapshot mirrors it through the point cloud slice.
