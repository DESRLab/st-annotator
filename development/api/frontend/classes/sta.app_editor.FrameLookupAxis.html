      Gets each frame which index along this axis falls in the interval [idx - idxRange, idx + idxRange] with respect to a query frame.

      idx refers to the index of the value of frame along this axis.

      If the value of frame along this axis is null, instead returns all frames that also have a null value along this axis.

    frameIdxDistance

    • frameIdxDistance(
          a: EditableFrame,
          b: EditableFrame,
          options?: AxisSearchOptions,
      ): number

      Computes the distance between two frames, in terms of their index along this axis.

      Frames may have an index of null as described in FrameLookupAxis#getFrameIdx. In that case, the distance between null and itself is zero, while the distance between null and a number is infinity.

      Parameters

      • a: EditableFrame

        The first frame.

      • b: EditableFrame

        The second frame.

      • options: AxisSearchOptions = {}

        The options to apply to the search.

      Returns number
