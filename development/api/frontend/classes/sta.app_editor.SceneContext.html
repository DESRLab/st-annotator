    displayTaskSelectors

    • displayTaskSelectors(task: TaskState | null): Promise<void>

      Sets the active task and loads its source groups, label branches, and scene frames, but displays no frame.

      The initial load uses this before choosing a frame with SceneContext#displaySceneSelection, which needs the loaded groups and branches to resolve the frame's own scene. Selecting the frame only there means one frame is displayed per load.

      Requires that this context be bound to a LayerCollection (see SceneContext#bindLayers).

      Parameters

      • task: TaskState | null

      Returns Promise<void>

      • Defined in core/frontend/app/routes/editor/scene/SceneContext.tsx:418

    requireFrame

    • requireFrame(frame: EditableFrame): Promise<void>

      Requests that data be loaded in memory for a frame (in the current branch).

      Unlike SceneContext#displayFrame, the frame is not actually displayed to the user. However, subsequently calling SceneContext#displayFrame should almost immediately display the frame, since the data has already been loaded (unless the cache has expired).

      Requires that this context be bound to a LayerCollection (see SceneContext#bindLayers).

      Parameters

      • frame: EditableFrame

      Returns Promise<void>
