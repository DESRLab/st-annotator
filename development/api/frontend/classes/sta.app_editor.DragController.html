    Class DragController<T>

    Enables a pointer device to drag an object in a SceneWindow by hovering over and click-and-holding on it.

    Note that if multiple instances of this class are attached to the same window, they will receive pointer events independently. To avoid duplicate interactions, the object groups assigned to each instance should be non-overlapping.
