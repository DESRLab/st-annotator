    Class Timestamp

    Similar to Date, but stores the timestamp as a decimal value to achieve arbitrary precision.

    This is a value-based class.

    • new Timestamp(
          value?: string | number | Decimal | Timestamp | Readonly<Date>,
      ): Timestamp

      Creates a new timestamp with arbitrary precision.

      Parameters

      • Optionalvalue: string | number | Decimal | Timestamp | Readonly<Date>

        This can be one of:

        • The number of milliseconds since midnight, January 1, 1970 UTC. May be a floating-point or decimal value.
        • A string value representing a date that can be parsed according to DateConstructor.parse. May contain additional digits after milliseconds.
        • A existing Date object which has millisecond-level precision.
        • An existing Timestamp object which has arbitrary precision.

        Defaults to the current date and time, with arbitrary precision.

      Returns Timestamp
