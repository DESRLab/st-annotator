    findInRangeOfFrame

    • findInRangeOfFrame(
          frame: EditableFrame,
          idxRange: Partial<Record<NavigatorAxisType, number>>,
          options?: AxisSearchOptions & IndexSearchOptions,
      ): readonly EditableFrame[]

      Gets each frame within a range of a reference frame along each axis.

      For each axis, if the value of the reference frame is null, only frames that also have a null value are returned; otherwise, only frames that are within the maximum distance (inclusive) along that axis are returned.

      Parameters

      • frame: EditableFrame

        The reference frame.

      • idxRange: Partial<Record<NavigatorAxisType, number>>

        For each axis, the maximum distance from the index of the reference frame to query; if null, instead queries the frames that also have a null value. If an axis is not specified, it is excluded from the search.

      • options: AxisSearchOptions & IndexSearchOptions = {}

        The options to apply to the search.

      Returns readonly EditableFrame[]

      The requested frames.

    frameIdxDistance

    • frameIdxDistance(
          a: EditableFrame,
          b: EditableFrame,
          options?: AxisSearchOptions,
      ): number

      Computes the distance between two frames, in terms of a Cartesian space formed from the index of each frame along each axis.

      Frames may have an index of null as described in FrameLookupAxis#getFrameIdx. In that case, the distance between null and itself is zero, while the distance between null and a number is infinity.

      Parameters

      • a: EditableFrame

        The first frame.

      • b: EditableFrame

        The second frame.

      • options: AxisSearchOptions = {}

        The options to apply to the search.

      Returns number

      The index-based distance between the two frames.
