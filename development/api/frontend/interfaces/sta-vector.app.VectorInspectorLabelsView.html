    Interface VectorInspectorLabelsView

    The narrow, structural surface of the vector labels view consumed by the inspector: the current labels index, the entity query accessors, the label mutation APIs, and the load events. Deliberately declares no three.js-facing members. The concrete VectorView satisfies this structurally.
