    Interface SegmentationInspectorLabelsView

    The narrow, structural surface of the segmentation labels view consumed by the inspectors: the current labels index, the entity query accessors, the label mutation APIs, and the load events. Deliberately declares no three.js-facing members. The concrete SegmentationView satisfies this structurally.
