    Interface StaE2EProbe

    The read-only projection probe API exposed on window.__STA_E2E_PROBE__.

    All returned coordinates are viewport-space (the main window rect origin, no scroll offset), ready for page.mouse. Methods return null when the requested target does not exist in the live scene (no active selection, unknown target id, or index out of range).
