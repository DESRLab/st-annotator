# ⭐ Vector Labels Plugin

This plugin enables the ST Annotator platform to represent points, paths, and regions as vector labels.

Each label contains a single point, an open polyline, or a polygon defined by vertices in three-dimensional space. An object class describes what the geometry represents, and an optional timestamp associates it with a particular time.

Vector labels belong to a labelset and share its version history. They can be exported as `.json` files.
