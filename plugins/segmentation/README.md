# ⭐ Segmentation Labels Plugin

This plugin enables the ST Annotator platform to represent objects and regions as selections of points in a point cloud.

Each selection contains the points belonging to a labelled object or region at a particular time. Selections can belong to a shared instance, which represents the same object across observations and carries its object class. Individual selections can also record a perceived class, quality, distinctiveness, and occlusion.

Segmentation labels belong to a labelset and share its version history. They can be exported as `.json` files.
