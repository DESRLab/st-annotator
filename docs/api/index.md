# ⭐ API Reference

We provide API documentation for the library code, which includes the following packages:

- [Frontend](./frontend/index.html)
- [Backend](./backend/python/index.html)

The frontend reference covers **every publishable frontend package** of the
workspace: the core `sta` package and each label plugin package
(`sta-bbox`, `sta-gmesh`, `sta-pcd`, `sta-segmentation`, `sta-vector`). Each
package contributes the modules named by the subpaths of its `package.json`
`exports` map, so the reference matches what a consumer can import. It is
generated from the workspace configuration in `typedoc.json`.

The backend reference covers the core `sta` Python package only; plugin
backends such as `sta_pcd` are not included — for those, read the plugin's own
source under `plugins/<name>/backend/`.

Both targets are generated by `bash scripts/doc.sh`. A tracked stub stands in for
each one in this tree, so that `mkdocs build --strict` has something to resolve the
nav against before the generated reference is copied over it.
