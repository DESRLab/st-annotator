# ⭐ Installation Guide

Thank you for your interest in this project! Please follow these instructions to install ST Annotator.

## Build from source

### Requirements

- Linux environment
- [npm](https://www.npmjs.com/) 9+
- [Python](https://www.python.org/) 3.10+
- [Poetry](https://python-poetry.org/) 2.1+

### Procedure

1. Clone this repository to your machine.
2. Activate a virtual Python environment (e.g. [conda](https://docs.conda.io/en/latest/)).
3. Run `bash ./scripts/install.sh` to setup and build the packages for both frontend and backend. This can take a few minutes to complete, so please be patient.
