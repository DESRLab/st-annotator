# ⭐ Roadmap

While this platform is ready for use, there are still a few improvements to be made:

- Extend the configuration files to work on the frontend as well so that there is no need to manually build another script file.
- Importers to facilitate demonstrating the platform on popular datasets.

Further down the line, we plan to have:

- An interface to resolve merge conflicts.
- Customizable keybinds for the annotation editor.
- Customizable theme for the web interface of the ST Annotator platform.
- More sophisticated plugins that can match the functionality of existing commercial software.
