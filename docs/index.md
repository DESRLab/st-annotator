# ⭐ ST Annotator

--8<-- "README.md:3:3"

## Features

- **Reusable data groups.** ST Annotator organizes data and their metadata into groups so that you can easily reuse them between projects.
- **Decoupled data types.** ST Annotator assumes no dependencies between data types for annotation, making it straightforward to mix-and-match data of different types to form a new dataset.
- **Project management.** ST Annotator organizes the annotation workload into a hierarchy of projects, tasks, and frames, giving you fine-grained control when assigning work to annotators.
- **Detailed annotation history.** ST Annotator implements [Git](https://git-scm.com/)-like version control for each operation made to a dataset so that you can review the annotation process in detail.
